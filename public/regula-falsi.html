Dashboard Metode Bagi Dua Metode Regula Falsi

Ringkasan

Regula falsi menggunakan interpolasi linear untuk membentuk perkiraan akar baru, tetapi tetap menjaga interval yang memuat akar.

  • Sering lebih cepat
  • Berbasis garis lurus
  • Memerlukan tanda berbeda

Metode Regula Falsi

Pencarian akar persamaan nonlinier dengan pendekatan garis lurus.

Rumus Inti

c = (a·f(b) - b·f(a)) / (f(b) - f(a))

Langkah Singkat

  1. Tentukan interval awal [a, b].
  2. Hitung titik pendekatan c.
  3. Evaluasi f(c) dan pilih interval baru.
  4. Ulangi sampai error memenuhi toleransi.

Petunjuk Input

  • Gunakan variabel x.
  • Gunakan tanda ^ untuk perpangkatan, misalnya x^3.
  • Pastikan f(a) × f(b) < 0.
  • Contoh fungsi: x^3 - x - 2.
  • Fungsi trigonometri seperti sin(x), cos(x), dan tan(x) menggunakan satuan radian.
